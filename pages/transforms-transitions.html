Transforms & Transitions

Transforms physically spin, scale, or shift elements without breaking document layout, while transitions smoothly blend state changes over time instead of snapping instantly.

Combine transform with transition for buttery-smooth interactive UI feedback.

Magic Wand Controls

  • scale(): Grows or shrinks an element (e.g. scale(1.1)).
  • rotate(): Tilts elements by specified degrees (e.g. rotate(15deg)).
  • translate(): Shifts elements horizontally (X) or vertically (Y).
  • transition: Controls property name, duration (e.g. 0.3s), and timing function (e.g. ease).
