Modern Layouts

Display & Flexbox

The display property dictates how an element occupies space on a page, while Flexbox (display: flex) unlocks flexible, responsive row/column alignment.

Key Flex properties: flex-direction, justify-content, and align-items.

Next Lesson →

Display Values

  • block: Starts on new line, takes full available width.
  • inline: Sits side-by-side on same line, ignores width/height.
  • inline-block: Sits side-by-side while respecting width/height.
  • flex: Creates dynamic multi-item row or column layouts.
  • justify-content: Aligns items along main axis (e.g. space-between, center).
