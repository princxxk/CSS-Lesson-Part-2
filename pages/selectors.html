Targeting Elements

CSS Selectors

The standard syntax formula for styling is selector { property: value; }. You use selectors to tell CSS which HTML elements you want to style.

There are 4 main ways to write selectors in your stylesheet.

Next Lesson →

4 Types of Selectors

  • 1. Universal (*): Selects everything on the page (e.g., * { font-family: Arial; }).
  • 2. Element: Targets specific HTML tags directly (e.g., p { color: white; }).
  • 3. Class (.): Targets elements with a class attribute (e.g., .card { background: #ffffff; }).
  • 4. ID (#): Targets one unique element (e.g., #main-title { font-size: 48px; }).
