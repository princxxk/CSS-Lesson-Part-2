Core Concept

CSS Box Model

Every element in CSS is wrapped in a box. Understanding the 4 layers (Content, Padding, Border, Margin) gives you complete control over spacing and layout.

Memory Trick: Padding is inside the border. Margin is outside the border.

Next Lesson →

The 4 Box Model Parts

  • Content: The actual text, images, or media inside the box.
  • Padding: Space inside the box, between the content and the border.
  • Border: The outline surrounding the content and padding.
  • Margin: Space outside the border, separating it from other boxes.
