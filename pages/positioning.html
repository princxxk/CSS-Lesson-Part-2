Layout Control

CSS Position & Z-Index

Positioning dictates where an element appears on screen and how it interacts with scrolling, while z-index controls the layering order of overlapping elements.

5 main position values: static, relative, absolute, fixed, sticky.

Next Lesson →

Position Types & Layers

  • Static: Default flow. Ignores top/bottom/left/right.
  • Relative: Shifted relative to its normal position without breaking page flow.
  • Absolute: Removed from flow, positioned relative to nearest positioned parent.
  • Fixed / Sticky: Fixed stays stuck to viewport; Sticky sticks after hitting a scroll threshold.
  • Z-Index: Stack layers (Higher wins, e.g., z-index: 10 on top of 1).
