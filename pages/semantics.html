Structure & Meaning

Semantic HTML

Semantic tags clearly describe their meaning to both the browser and developer. Instead of using generic div tags for everything, semantic tags give web pages meaningful structure.

Semantic HTML gives built-in meaning and structure to browsers, search engines, and screen readers.

NEXT LESSON →

Key Semantic Tags

  • header: Top bar containing site branding, logo, or navigation.
  • nav: Container specifically for navigation links.
  • main: Dominant, unique body content of the document.
  • article & section: Self-contained thematic blocks of content.
  • aside: Related sidebars or callout boxes.
  • footer: Copyright info, contact links, or metadata at the bottom.
