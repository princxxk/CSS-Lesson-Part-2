Sub-Element Styling

CSS Pseudo-Elements

Pseudo-elements allow you to style specific sub-parts of an element or inject decorative content dynamically using pure CSS.

Pseudo-elements begin with a double colon (e.g., ::before, ::after, ::first-letter).

Next Lesson →

Common Pseudo-Elements

  • ::before / ::after: Inserts decorative generated content before/after an element's text.
  • ::first-letter / ::first-line: Styles drop caps or initial line highlights independently.
  • ::selection: Customizes highlight color when users click and drag text.
  • ::placeholder: Styles input prompt text inside forms.
